Modal Pop-Up

Hi! This is a modal. Click outside or the × button to close.

You can add forms, messages, or anything here.

:mirror_ball: JavaScript Modal Pop-Up
Afrofuturism Dark Mode Lesson

Step 1: Project Setup

  1. Open VSCode.
  2. Create a new folder called modal-lesson.
  3. Inside it, create index.html.
  4. Paste this starter code:
<!DOCTYPE html>
<html>
<head>
  <title>Modal Example</title>
</head>
<body style="background:#13171A; color:#F6F7F8;">
<button onclick="openModal()">Show Modal!</button>
<div id="modalBackdrop" style="display:none;position:fixed;z-index:2000;left:0;top:0;width:100vw;height:100vh;background:rgba(0,0,0,0.8);">
  <div style="background:#191d1f;padding:2em 1.5em;border-radius:20px;max-width:350px;margin:100px auto;">
    <p>This is a modal pop-up!</p>
    <button onclick="closeModal()">Close</button>
  </div>
</div>
<script>
  function openModal() {
    document.getElementById('modalBackdrop').style.display = 'block';
  }
  function closeModal() {
    document.getElementById('modalBackdrop').style.display = 'none';
  }
</script>
</body>
</html>

Step 2: How the Modal Works

  • A button calls openModal() to show ("pop up") the modal.
  • The modal is a div that covers the screen and contains a message and close button.
  • closeModal() hides it.
  • Styling and JS can be improved (see next step!)
<button onclick="openModal()">Show Modal</button>

Step 3: Try It Out!

  1. Open your index.html in the browser.
  2. Click the Show Modal! button. See the pop-up!
  3. Click Close or outside modal to dismiss.
