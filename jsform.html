:memo: JavaScript Form Submission
Semani/DeeBee Edition

Step 1: Set Up Your Project

  1. Open VSCode (or your favorite editor).
  2. Create a folder named js-form-submission.
  3. Inside, create a file called index.html.
  4. Start with this HTML in index.html:
<!DOCTYPE html>
<html>
<head>
  <title>Form Submission Example</title>
</head>
<body style="background:#0c0c0c">
  <h2>Enter Your Name</h2>
  <form id="myForm">
    <input type="text" id="nameInput" placeholder="Your name">
    <input type="submit" value="Submit">
  </form>
  <p id="result"></p>
  <script>
    // JavaScript will go here
  </script>
</body>
</html>

Step 2: Handle the Form Submission

  1. Inside the <script> tags, add this code:
document.getElementById("myForm").addEventListener("submit", function(event) {
  event.preventDefault(); // Stops the form from refreshing the page
  let name = document.getElementById("nameInput").value;
  document.getElementById("result").innerHTML = "Hello, " + name + "! :wave:";
});

Your file should now look like:

<!DOCTYPE html>
<html>
<head>
  <title>Form Submission Example</title>
</head>
<body style="background:#0c0c0c">
  <h2>Enter Your Name</h2>

    <input type="submit" value="Submit">
  </form>
  <p id="result"></p>
  <script>
    document.getElementById("myForm").addEventListener("submit", function(event) {
      event.preventDefault();
      let name = document.getElementById("nameInput").value;
      document.getElementById("result").innerHTML = "Hello, " + name + "! :wave:";
    });
  </script>
</body>
</html>

Step 3: See It Live!

  1. Save your file.
  2. Open index.html in your browser.
  3. Type your name and submit the form.
    You’ll see a custom greeting below the form!
